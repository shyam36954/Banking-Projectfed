# Evergreen Online Banking

A small SDC project made with HTML, CSS and JavaScript.

## Run

Keep `index.html`, `style.css`, and `app.js` together, then open `index.html` in a browser.

## Included

- User signup and login stored in Local Storage
- Separate User and Admin modules with JavaScript navigation
- Responsive CSS Grid layout
- PIN check for the customer balance
- Customer loan requests and admin approval
- Three disabled dashboard sidebar buttons: Transfer money, Scan QR and Pay bill

The three sidebar buttons are display-only placeholders. The loan request remains a separate working feature.

New accounts start at ₹0. Passwords and data are stored in the browser for demonstration only. This is not a real banking service.
